# DevGod logo

[devgod-logo.png](devgod-logo.png) is the project emblem used in the root README. Its opaque plum background keeps the ivory candle and gold crescent legible on both light and dark pages. The README renders the square mark at 220 × 220 pixels and supplies the project name as accessible text.

Created and refined on September 12, 2026 with the built-in image generation tool, directed for this repository. The final generated PNG is preserved without further image edits, including its provenance metadata. The asset is distributed under the repository's [MIT license](../../LICENSE).

The visual direction draws on [Eimi's profile README](https://github.com/WitchyNibbles): candlelight, understated gothic imagery, and playful language around reliable software.

```text
Color palette: near-black plum #17121f, warm ivory #efe3cd, muted antique gold #b69a62, small blood-red #b74353 accent. Opaque dark medallion ensures the ivory symbol works against both light and dark GitHub themes.
Text: none. The README will supply the DevGod wordmark as accessible real text.
Constraints: one finished logo, no presentation board, no mockup, no extra objects, no lettering, no watermark, no pentagram, no gradients, no shadows or glow. Genuine transparent pixels outside the medallion, never a simulated checkerboard.
```
